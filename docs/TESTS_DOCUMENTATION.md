
## ملخص مجموعات الاختبار (11 مجموعة / 44 اختباراً)

1. **`FinancialCalculatorTest` (6/6 ناجحة):**
   - حسابات الاستهلاك، الكسور والتقريب المالي، الفواتير، ترحيل المتأخرات، الرصيد الدائن، وإعادة التسعير.
2. **`AlasalDatabaseAndRelationsTest` (9/9 ناجحة):**
   - التحقق من الجداول الأربعة عشر والعلاقات المرجعية (`SubscriberFullHistory`).
   - قيود التفرد (رقم العداد، قراءة واحدة لكل فترة) والمفاتيح الأجنبية.
   - كافة الترقيات غير الهدّامة: `MIGRATION_1_2`، `MIGRATION_2_3`، `MIGRATION_3_4`، و**`MIGRATION_4_5`** (إضافة `biometric_enabled`).
3. **`Phase2BillingAndTariffTest` (5/5 ناجحة):**
   - تحديث أسعار الكيلوواط (فردي، مجموعة، شامل) مع الحفاظ على الفواتير القديمة، ومنع تكرار ترحيل المتأخرات، وخصم الرصيد الدائن مرة واحدة، وإعادة التسعير، ورفض القراءة الأقل ومنع الحذف مع وجود سجل مالي.
4. **`Phase3CollectionsReportsAndPrintTest` (4/4 ناجحة):**
   - التحصيل الكامل والجزئي والمتعدد، وثبات أرقام الإيصالات، والتقارير الـ9 وكشف الحساب، وتوليد ملفات PDF (A4 و58mm و80mm) وPNG و`FileProvider`، والتذكيرات و`ReadingReminderWorker`.
5. **`Phase4AccountsSyncBackupRestoreTest` (4/4 ناجحة):**
   - الحسابات والصلاحيات مع المنع البرمجي، ومزامنة Wi-Fi ثنائية الاتجاه، والنسخ الاحتياطي، وكافة اختبارات فشل الاستعادة الإلزامية مع التراجع الذري الآمن عبر 18 خطوة.
6. **`Phase5FinalAuditAndPerformanceTest` (3/3 ناجحة):**
   - التدقيق المالي الصارم عبر الحذف وإعادة التشغيل، واستمرارية التفضيلات وواتساب، واختبار الضغط والأداء (400 مشترك و400 فاتورة و250 تحصيل ونسخ واستعادة).
7. **`Phase6AutomationStatementsSecurityTest` (5/5 ناجحة):**
   - تحديث سعر الكيلوواط مباشرة للمشترك الواحد مع بقاء الفواتير القديمة ثابتة وتطبيق السعر الجديد مستقبلاً.
   - المعالجة الذكية لأرقام الهواتف لواتساب وإطلاق `ACTION_VIEW` (`https://wa.me/...`) للفواتير والإيصالات وكشوف الحساب وإرجاع تحذيرات عربية صريحة عند غياب أو عدم صلاحية الرقم.
   - تصفية كشف النزول الميداني حسب المنطقة والمديونية وتصدير ملف **A4 PDF** (`%PDF-`) وملف **Excel CSV** بترميز **UTF-8 BOM** (`EF BB BF`) وأعمدة عربية كاملة.
   - دورة قفل التطبيق، ورفض كلمة المرور الخاطئة، وحفظ خيار البصمة لكل مستخدم في Room v5، والقفل التلقائي في الخلفية وبانتهاء مهلة عدم النشاط، وتسجيل الدخول بالبصمة في `financial_audit_logs`.
8. **`AlasalUiAndLaunchRobolectricTest` (5/5 ناجحة):**
   - اختبارات واجهة Jetpack Compose الكاملة (المشتركين، القراءات، الفواتير، التحصيل، التقارير، التذكيرات، الحسابات، المزامنة والنسخ، الأيقونات والعلامة المائية، و`StationMaintenanceWorker`).
9. **`Phase6UiAndSecurityRobolectricTest` (1/1 ناجحة):**
   - تدفق واجهة المستخدم الشامل للمرحلة السادسة: خطأ القفل -> فتح القفل بكلمة المرور `2027` -> تعديل سعر الكيلوواط من ملف المشترك -> التحقق من شريط الإرسال الفوري لواتساب بعد إصدار الفاتورة -> كشف النزول الميداني وتصفية المنطقة وأزرار PDF/CSV -> تفعيل البصمة للحساب -> القفل اليدوي وظهور زر البصمة مع كلمة المرور البديلة.
10. **`ExampleRobolectricTest` (1/1) و`ExampleUnitTest` (1/1):**
    - التحقق من موارد التطبيق الأساسية والبيئة الاختبارية.

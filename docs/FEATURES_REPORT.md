# تقرير المميزات المنفذة — محطة العسل 2027 (Alasal2027)

## 1. الهوية البصرية وتجربة المستخدم الاحترافية (UI/UX)
- دعم كامل للغة العربية واتجاه RTL في جميع الشاشات والحوارات والتقارير والطباعة.
- واجهات Material Design 3 محسّنة تجارياً بالهوية المعتمدة (الأزرق الداكن، الذهبي، الأصفر، الأخضر للأرصدة الدائنة، الأحمر للمتأخرات)، مع انتقالات `NavHost` سلسة، وتحسين البطاقات والحواف والظلال، وزر القفل الفوري في الترويسة.
- علامة مائية شفافة، وأيقونة تطبيق تكيفية مخصصة (Adaptive Icon)، ودعم الوضع الليلي والنهاري والتلقائي.
- تخطيط متكيف للهواتف والأجهزة اللوحية (`NavigationBar` للشاشات الضيقة و`NavigationRail` للشاشات العريضة).

## 2. إدارة المشتركين والأسعار (بما فيها التعديل المباشر من ملف المشترك)
- سجل مشتركين كامل (الاسم، رقم المشترك، الهاتف، العنوان/المنطقة، رقم العداد، رقم الختم، السعر المستقل، تاريخ الاشتراك، الحالة، الرصيد الدائن، الملاحظات).
- تعديل سعر الكيلوواط مباشرة داخل نافذة تفاصيل/ملف المشترك (`SubscriberDetailDialog`) ليُطبّق على الفواتير الجديدة فقط مع توثيقه في سجل تغييرات الأسعار دون أي تأثير على الفواتير القديمة.
- دعم إدارة الأسعار المركزية لمشترك واحد أو مجموعة مختارة أو لجميع المشتركين مع معاينة التأثير قبل الاعتماد.
- البحث بالاسم أو رقم المشترك أو الهاتف أو رقم العداد، ومنع حذف أي مشترك لديه سجلات مالية.

## 3. قراءات العدادات والفواتير والمتأخرات والأرصدة الدائنة
- تسجيل القراءات مع منع التكرار لنفس الفترة، ورفض القراءة الأقل من السابقة إلا بصلاحية وتأكيد المدير مع ذكر السبب، ودعم إرفاق صورة العداد عبر Photo Picker دون أذونات تخزين عريضة.
- حساب تلقائي للاستهلاك والمبلغ، وترحيل المتأخرات غير المرحلة فقط دون تكرار الدين.
- خصم الرصيد الدائن مرة واحدة فقط وتوثيقه في دفتر حركات الدائن، وإضافة فائض السداد إلى الرصيد الدائن تلقائياً.
- دعم إعادة تسعير الفواتير القديمة بصلاحية مخصصة مع الحفاظ على التحصيلات السابقة وتسوية الفرق مالياً.

## 4. التحصيل والإيصالات والتقارير وكشوف النزول الميداني وأتمتة واتساب
- دعم التحصيل الكامل، الجزئي، وتعدد التحصيلات للفاتورة الواحدة مع أرقام تسلسلية غير متكررة (`INV-2027-XXXX`, `COL-2027-XXXX`, `RCP-2027-XXXX`).
- **أتمتة الإرسال الفوري عبر واتساب:** معالجة ذكية لأرقام الهواتف وفق رمز الدولة القابل للتخصيص (افتراضياً `967`) مع رسائل تحذير عربية صريحة عند نقص أو عدم صلاحية الرقم، وإرسال فوري مباشر من بطاقة ما بعد إصدار الفاتورة، وقائمة وتفاصيل الفواتير، ونافذة الإيصال، وكشوف حساب المشتركين.
- **قسم كشوف الحساب والتحصيل الميداني المخصص:** تصفية حسب المنطقة/العنوان وحالة المديونية (`عليه متأخرات فقط`، `بدون متأخرات`، `الجميع`) وتصدير وطباعة كشف النزول الميداني بصيغتي **A4 PDF** و**Excel CSV** (بترميز UTF-8 BOM الداعم للعربية في Excel وGoogle Sheets) متضمناً الكود، الاسم، المنطقة، الهاتف، القراءة السابقة، المستحق، وحقلاً فارغاً للتحصيل والتوقيع اليدوي.
- تصميم إيصال رسمي وتوليد A4 PDF وPNG وصيغ الطباعة الحرارية 58mm و80mm دون إنترنت.

## 5. الحماية والبصمة والتذكيرات والمزامنة والنسخ الاحتياطي الآمن
- **شاشة قفل وحماية التطبيق:** قفل إلزامي عند التشغيل أو الرجوع من الخلفية أو انتهاء مهلة عدم النشاط (مع قفل فوري بضغطة زر)، ودعم التحقق بالبصمة عبر `BiometricPrompt` القابل للتخصيص لكل مستخدم، مع بقاء كلمة المرور متاحة كخيار بديل إلزامي دائماً.
- جدولة التذكيرات وإشعارات النظام بالصوت أو الصامت مع زر الإشعار الاختباري، والتكامل مع `WorkManager`.
- حسابات متعددة الأدوار (المدير الرئيسي، الحسابات الفرعية، المحصلين) مع مصفوفة 19 صلاحية والتحقق البرمجي الفعلي.
- مزامنة محلية عبر Wi-Fi (TCP Sockets + NSD + إدخال IP يدوي) ونسخ احتياطي يدوي ويومي تلقائي وحفظ عبر SAF والمشاركة/الرفع لـGoogle Drive، مع بروتوكول **الاستعادة الآمنة عبر 18 خطوة**.
